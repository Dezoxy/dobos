# Security

This is a personal fork of [MrRobotoGit/tiramisu](https://github.com/MrRobotoGit/tiramisu).
Report a vulnerability in the fork's own changes (see [FORK.md](FORK.md)) privately through
GitHub's **Report a vulnerability** button on this repository. Report issues in upstream code
to upstream.

Tiramisu's Control Panel and APIs have no authentication. Bind them to loopback or a private
network, never to an address other people can reach.
